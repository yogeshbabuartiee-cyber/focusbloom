# 🌱 FocusBloom

**Grow your focus. Bloom your potential.**

FocusBloom is a productivity web app designed to help students build better study habits using a Pomodoro timer, breaks, task management, and session tracking.

## ✨ Features

- ⏱️ Focus timer with start, pause, and reset controls
- ☕ Short breaks and long breaks
- 🔔 Browser notifications when sessions finish
- ✅ Add, complete, and delete tasks
- 💾 Save tasks and completed focus sessions using browser local storage
- 🎨 Simple, responsive user interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage API
- Browser Notifications API

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start a focus session and add your tasks.

No additional installation is required.
